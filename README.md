# 1DAW - Materiales, Apuntes y Practicas

Repositorio con el material de estudio, apuntes, ejercicios y evaluaciones correspondientes a 1º del ciclo superior Desarrollo de Aplicaciones Web (1DAW).

## Modulos Incluidos

- `Programacion/`: Ejercicios, algoritmos y estructuras de datos en Java.
- `BasesDatos/`: Consultas SQL, diagramas entidad-relacion y diseno relacional.
- `LenguajeMarcas/`: Documentos XML, XSD, XSLT, HTML5 y CSS3.
- `Hacking1DAWhtml/`: Practicas de analisis web y seguridad en entornos formativos.
